# System Monitor 설계

날짜: 2026-11-13
상태: 승인됨

## 의도

Mac과 Windows에서 작업 중 시스템 자원 상태(CPU, GPU, 메모리, 디스크 저장공간)를
한눈에 확인할 수 있는 가벼운 모니터링 프로그램.

처음 요청은 디스크 조각 모음 도구였으나, Mac(APFS/SSD)에서는 조각 모음이 불가능하고
SSD에서는 의미가 없어 사용자가 자원 모니터링으로 방향을 바꿨다.

## 목표

- CPU 사용률(전체 + 코어별), GPU 사용률, 메모리 사용량, 디스크 여유 공간을 1초 주기로 표시
- 메뉴 막대(Mac) / 트레이(Windows) 아이콘에서 여는 작은 위젯 창
- 위젯 창 항상 위 고정 옵션
- 관리자 권한 없이 동작
- 모니터 자체가 가벼울 것 (RAM 수십 MB 수준)

## 비목표 (첫 버전 제외)

- 프로세스별 목록
- 온도 / 팬 속도 (Mac에서 비공개 API 필요)
- 경고 알림
- 기록 저장
- 디스크 조각 모음

## 반(反)목표

- 모니터가 눈에 띄게 CPU/RAM을 소비하는 것
- 관리자 권한을 요구하는 것

## 접근 방식

| 방식 | 장단점 |
|------|--------|
| **Rust + Tauri (선택)** | 한 코드로 양쪽 OS, 가벼움, OS API 직접 호출 가능 |
| Electron | 개발은 쉽지만 RAM 200MB 이상 — 목적에 어긋남 |
| OS별 네이티브 (Swift + C#) | OS 공식 위젯 영역 가능하나 두 번 구현 |

언어·프레임워크 선택은 사용자가 맡겼고, 위 선택은 구현자의 결정이다.

## 구조

- **수집 (Rust 백엔드)**
  - CPU / 메모리 / 디스크: `sysinfo` 크레이트
  - GPU (Windows): PDH 성능 카운터 `\GPU Engine(*)\Utilization Percentage` (작업 관리자와 동일 출처)
  - GPU (macOS): IOKit `IOAccelerator`의 `PerformanceStatistics` → `Device Utilization %`
  - GPU 값을 읽지 못하면 `None` → 화면에 "N/A"
  - 1초 주기 백그라운드 스레드가 스냅샷을 만들어 Tauri 이벤트로 프런트엔드에 전송
- **화면 (웹 프런트엔드, 프레임워크 없는 HTML/CSS/JS)**
  - 행 4개: CPU, GPU, MEM, DISK
  - CPU/GPU는 최근 60초 스파크라인, MEM/DISK는 사용량 막대
  - 핀 버튼으로 항상 위 고정 토글
- **트레이 / 메뉴 막대**
  - 아이콘 클릭 시 위젯 창 표시/숨김
  - Mac 메뉴 막대 제목에 CPU·MEM 요약 수치
  - 메뉴: 열기, 종료
  - 창을 닫아도 앱은 트레이에 남음

## 검증

- macOS: 이 기기에서 빌드 및 실행 확인
- Windows: 코드는 작성하나 이 환경에서 실행 불가 — 사용자가 Windows PC에서 빌드해 확인
- 순수 로직(스냅샷 계산, 히스토리 버퍼, 포맷)은 단위 테스트

## 구현자에게 맡기는 것

- 창 크기, 색상, 글꼴 등 세부 스타일
- 크레이트 버전 선택
- 모듈 분리 방식
