# 디자인 참고 노트

위젯 화면을 새로 그리면서 참고한 데스크톱 펫 앱(Electron)에서 **무엇을 가져오고 무엇을 가져오지 않는지** 적어 둡니다.

## 원칙

- 참고 앱의 캐릭터는 남의 저작물입니다. 그 앱의 이미지·스프라이트·글꼴 파일은 이 저장소에 넣지 않습니다.
  따라 그리기, 색만 바꾸기, 줄여 쓰기도 하지 않습니다. 그 캐릭터로 알아볼 수 있는 생김새나 이름도 쓰지 않습니다.
- 가져오는 것은 디자인 요소입니다: 색 조합, 글꼴의 느낌, 모서리·테두리·그림자, 여백, 애니메이션 기법.
- 위젯의 마스코트와 아이콘은 이 저장소에서 새로 그린 SVG입니다(아래 "새로 그린 것").
- 이 문서에는 참고 앱의 그림을 싣지 않습니다. 숫자와 글로만 적습니다.

## 참고 앱에서 읽은 것

읽은 곳: 펫 창·TV 창·설정 창·말풍선·오른쪽 클릭 메뉴·시계의 CSS, 테마 표, 스프라이트 목록(동작별 프레임과 시간), 메뉴 막대 아이콘.

### 색

따뜻한 파스텔 바탕에 짙은 갈색 글자와 선. 검정·회색을 쓰지 않는 것이 특징입니다.

| 역할 | 값 | 쓰이는 곳 |
|------|-----|-----------|
| 버터(바탕) | `#ffe9a6` | 창 바탕. 흰 점무늬가 깔림 |
| 버터 진한 색 | `#f7d36d` | 주 버튼, 켜진 스위치 |
| 크림(종이) | `#fff8e6` | 카드, 말풍선 안쪽 |
| 블러시 | `#ffd5dc` | 선반, 제목 스티커, 버튼 hover |
| 블러시 진한 색 | `#f5a9b8` | 말풍선 테두리, 포커스 링 |
| 강조 | `#e77f95` | 체크, 머리말 점 |
| 민트 | `#dff1d8` | 켜진 상태 알약 |
| 하늘 | `#dcedfc` | 보조 알약, 아바타 바탕 |
| 글자(ink) | `#4a3524` | 본문 |
| 선(line) | `#6b4f3a` | 모든 테두리, 그림자 색의 바탕 |
| 흐린 글자 | `#8a6a50`, `#7a6350` | 보조 설명 |
| 구분선 | `#f1dcc0`, `rgba(107,79,58,.22)` | 목록 구분 |
| 위험 | `#ad4259` | 삭제류 |

- 테마가 캐릭터마다 있고 같은 일곱 역할(바탕, 바탕 진한 색, 선반, 선반 진한 색, 종이, 민트, 강조)만 바꿉니다.
  예: 분홍 `#ffdfe5 / #f7b3c2 / #fff1f3 / #ee94a8 / #fffaf5`, 하늘 `#c9e4fb / #8dc3ee / #e8f4ff / #5fa6dc / #f7fbff`(강조 `#4f9ad6`).
  글자·선 색은 모든 테마에서 같습니다.
- 바탕 점무늬: `radial-gradient(circle at 12px 12px, rgba(255,255,255,.55) 3px, transparent 4px)`, 34px 간격.
- 바탕 색은 글자색 대비 4.5:1 이상을 지키도록 밝기를 고릅니다.
- **어두운 테마는 없습니다.** 어두운 쪽 색은 이 저장소에서 같은 규칙(따뜻한 색, 갈색 계열 선)으로 새로 정했습니다.

### 글꼴의 느낌

- 제목·버튼·숫자: 획 끝이 둥근 굵은 고딕(둥근 간판 글씨 느낌). 굵기 400 한 가지만 쓰고 크기로 위계를 줍니다(13–24px).
- 본문 일부: 손글씨풍. 긴 설명은 시스템 한글 고딕 14px, 줄 간격 1.55.
- 줄 간격이 좁고(1.15–1.35) 글자가 큼직합니다. 대문자 강조나 자간 조정은 없습니다.
- 글꼴 파일은 가져오지 않습니다. 위젯은 시스템의 둥근 글꼴(`ui-rounded`)을 먼저 쓰고, 없는 시스템(Windows)에서는
  시스템 고딕을 굵게 써서 비슷한 무게를 냅니다.

### 모서리 · 테두리 · 그림자

| 요소 | 값 |
|------|-----|
| 테두리 | 거의 모든 면에 `1.5px solid #6b4f3a`. 말풍선만 `2px solid #f5a9b8` |
| 알약(버튼, 입력, 스위치) | `border-radius: 999px` |
| 카드 | `22px` |
| 말풍선 · 메뉴 | `14–16px`, 안쪽 줄 `10–11px` |
| 아이콘 타일 | `26–28px` 정사각, `8px` |
| 손그림 모서리 | `26px 30px 27px 31px / 30px 26px 31px 27px`처럼 네 귀를 조금씩 다르게 |
| 그림자 | 흐림 없는 단색 오프셋. `0 2px 0 rgba(107,79,58,.35)`(버튼), `0 3px 0 rgba(107,79,58,.3)`(카드), `4px 5px 0 rgba(107,79,58,.3)`(큰 면) |
| 누름 | `translateY(1px)` + 그림자 없앰 |
| 스티커 | 제목을 `rotate(-1.5deg)`, 말풍선을 `rotate(-3deg)`로 살짝 기울임 |
| 스위치 | 34×20, 손잡이 13px, 켜지면 버터 진한 색 |
| 여백 | 줄 높이 34–38px, 줄 안쪽 `0 8px`, 아이콘과 글자 사이 10px, 카드 안쪽 16–18px |

흐린 그림자·반투명·블러를 쓰지 않아 종이 스티커를 붙인 것처럼 보입니다. 합성 레이어를 늘리지 않는다는 점에서 이 위젯의 메모리 제약과도 맞습니다.

### 애니메이션

캐릭터는 프레임(셀) 그림을 겹쳐 두고 **보이는 한 장만 불투명하게** 바꿉니다. 셀 사이는 끊어서 넘깁니다(전환 0ms).
다음 셀이 바뀔 시각에 맞춘 타이머 하나로 움직이고, 매 프레임 그리는 루프를 돌리지 않습니다.

| 동작 | 프레임 구성 | 한 바퀴 |
|------|-------------|---------|
| 가만히(깜빡임) | 2–6장. 뜬 눈 한 장을 2.4–2.8초 들고, 깜빡임 셀을 40–180ms씩 | 2.7–3.6초, 첫 셀 길이에 무작위 시간을 더해 불규칙하게 |
| 잠 | 4–18장, 장당 167–700ms | 약 3초 |
| 걷기 | 4–6장, 장당 110–140ms | 0.5초 |
| 뛰기 | 3–9장, 장당 60–375ms | 0.75초 |
| 잡힘 | 16–32장, 장당 50–100ms | 1.6초 |
| 한 번짜리 동작 | 12–29장, 장당 30–840ms(멈춤 셀을 길게) | 1–3초 |

초당 4–10장 정도의 낮은 프레임 수가 손그림 느낌을 냅니다.

그림 전체에 얹는 CSS 움직임(모두 `transform`/`opacity`만 사용):

| 이름 | 값 |
|------|-----|
| 숨쉬기(잠) | 4s ease-in-out 무한, `scale(1.025, 1.04)`까지 |
| 숨쉬기(평소) | 4.6s, `scale(1.008, 1.016)` · 2.4s, `scale(1.02, 1.03)` |
| 까딱(bob) | 0.5s ease-in-out alternate, `translateY(-4px)` |
| 깡충 | 0.6s ease-out: 눌림 `scale(1.08,.92)` → 뜀 `translateY(-18%) scale(.95,1.06)` → 착지 `scale(1.06,.94)` |
| 흔들림(알람) | 0.32s linear, `rotate(±4–5deg) translateX(±1–2px)` |
| 통 튀기 | 0.6s ease-out 한 번, `translateY(-6px) scale(1.03,.97)` |
| 말풍선 등장 | 0.12–0.14s ease-out, `scale(.92–.94)`+투명 → 제자리 |
| 콜론 깜빡임 | `1s steps(1)`, 50%에서 투명 |
| Zzz | 2.4s, 위로 6px 오르내리며 투명도 .5–.9 |

- 변형의 기준점은 발밑(`transform-origin: 50% 100%`)이라 숨쉴 때 발이 뜨지 않습니다.
- 상태(가만히, 걷기, 잠, 잡힘 …)는 바깥에서 정해 주고, 화면은 클래스 하나를 바꿔 끼웁니다.
- `prefers-reduced-motion`이면 움직임을 모두 끄고 대표 한 장만 보여 줍니다.

### 메뉴 막대 · 트레이 아이콘, 앱 아이콘

- 메뉴 막대: 20×20(@2x 40×40), Windows 트레이: 16 / 20 / 24 / 32px(배율별). 얼굴만 크게 잘라 넣은 색 있는 그림이고,
  템플릿(단색) 이미지가 아닙니다. 굵은 갈색 외곽선과 밝은 몸 색 덕에 밝은 막대·어두운 막대 모두에서 보입니다.
- 앱 아이콘: 1024px, 위는 분홍 아래는 크림인 세로 그라데이션 바탕에 굵은 외곽선의 얼굴.

## 위젯에 가져오는 것

| 요소 | 위젯에서 (`ui/style.css`) |
|------|----------|
| 색 | 버터 바탕 `#ffe9a6`(머리 부분에 흰 점무늬), 크림 카드 `#fff8e6`, 글자 `#4a3524`, 선 `#6b4f3a`. 항목 색은 블러시(CPU `#f5a9b8`)·하늘(GPU `#8dc3ee`)·버터(MEM `#f7d36d`)·민트(DISK `#a6d896`), 경고는 `#e8607c` |
| 글꼴 느낌 | 시스템 둥근 글꼴(`ui-rounded`)을 굵게(700–800), 숫자는 17px로 큼직하게. 없는 시스템은 시스템 고딕 굵게 |
| 테두리·그림자 | 1.5px 갈색 테두리, 흐림 없는 오프셋 그림자(`0 2px 0`, `0 3px 0`, 투명도 .35), 알약 모양 이름표·막대·버튼, 카드 모서리 14px, 말풍선 2px 블러시 테두리에 `rotate(-2deg)` |
| 누름 | 버튼을 누르거나 📌이 켜지면 `translateY(2px)` + 그림자 없앰, 켜진 📌은 버터 진한 색 |
| 애니메이션 | 낮은 프레임 수로 끊어 넘기는 움직임(`steps()`): 숨쉬기 4.6s `scale(1.02, 1.04)`(한 바퀴 4장), 까딱 0.6s `translateY(-3px)`(0.3초마다 한 장), 흔들림 2.4s마다 `rotate(±4–5deg)`, 땀방울·김. 기준점은 발밑 |
| 깜빡임 | 눈 뜬 채 2.4–4.0초(무작위), 감은 셀 130ms. 다음 변화 시각에 맞춘 타이머 하나로 클래스를 바꿈 |
| 상태 전환 | 측정값으로 한가함/바쁨/뜨거움을 정해(`moodOf`) `#mascot[data-mood]` 하나를 바꾸면 표정·움직임·말풍선이 따라감. 말풍선은 0.14s `scale(.92)`에서 등장 |
| 움직임 줄이기 | `prefers-reduced-motion`이면 모두 끄고, 창이 보이지 않으면 멈춤 |
| 아이콘 | 색 있는 그림 그대로인 메뉴 막대·트레이 아이콘(템플릿 이미지가 아님), 버터 바탕에 흰 점무늬와 갈색 테두리를 두른 앱 아이콘 |

참고 앱과 다르게 한 것:

- 점무늬는 페이지 전체가 아니라 머리 부분에만 SVG로 그립니다. 페이지 전체에 반복 gradient로 깔면 웹 프로세스 메모리가
  약 7 MiB 늘었습니다(측정).
- 프레임 그림을 바꿔 끼우는 대신 SVG 하나의 부품을 CSS로 움직입니다. 움직임은 작은 SVG 안에서만 일어나고
  `will-change`·3D 변형·블러·반투명 창을 쓰지 않습니다.
- 장면 수는 참고 앱(초당 4–10장)보다 적습니다(한가할 때 초당 1–2장, 바쁠 때 3장쯤). 한 장을 바꿀 때마다 웹·GPU·앱
  프로세스가 함께 일해서, 상시 움직임이 CPU를 눈에 띄게 씁니다(측정값은 README의 "CPU").

## 가져오지 않는 것

- 캐릭터 그림, 스프라이트, 아이콘 파일, 글꼴 파일.
- 캐릭터의 생김새와 이름, 캐릭터별 테마 이름.
- 수백 장의 프레임 이미지를 쓰는 방식. 위젯은 SVG 하나를 CSS로 움직입니다.

## 새로 그린 것

- 마스코트 **칩이**: 모서리가 둥근 네모 칩 몸에 양옆 핀(다리)이 달린 반도체 칩 캐릭터. 참고 앱의 동물 캐릭터와 겹치지 않는
  모양입니다. 인라인 SVG이고 표정(한가함/바쁨/뜨거움)은 SVG 안의 부품을 켜고 끄는 방식입니다.
- 앱 아이콘의 바탕: 버터색 둥근 사각형에 흰 점무늬와 갈색 테두리(`scripts/build-icons.sh` 안에서 그림). 그 위에 올리는 그림과 메뉴 막대·트레이 아이콘은 아래 "운영자가 넣은 그림"입니다.
